## PHASE 1: Hero Section + Mobile Navigation

```
You are building a premium landing page for O'Brien Marketing Group (OMG), a screen printing, embroidery, and vinyl wrap company based in Longview, Texas.

PROJECT OVERVIEW:
- Company: O'Brien Marketing Group
- Location: 605 Gilmer Rd, Longview, Texas
- Tagline: "We STRIVE so you THRIVE"
- Services: Screen Printing, Embroidery, Vinyl Wraps, Decals, Signs/Banners
- Contact: 903-212-3266 | sales@theOMGshop.com
- Website Domain: theomgshop.com (to be updated)

DESIGN SYSTEM:
- Primary Color: Lime Green (#1FFF00)
- Background Color: Black (#0A0A0A)
- Accent/Dark Gray: #1A1A1A
- Text Color: Light Gray (#E8E8E8)
- Font: System fonts (no external font libraries)
- Approach: Dark theme with lime green as primary design driver, modern and bold

PHASE 1 DELIVERABLES: Hero Section + Mobile-First Navigation

Create the following in index.html with embedded CSS and vanilla JavaScript:

1. FIXED NAVIGATION BAR (Mobile-First)
   - Fixed at top with dark background (semi-transparent with blur)
   - Logo/Brand name "OMG" on left (lime green, bold)
   - Navigation links on right: "Services", "Portfolio", "Contact" (hide on mobile, show on tablet+)
   - Hamburger menu icon (3 horizontal lines in lime green) on mobile/tablet
   - Hamburger toggles mobile menu that slides down
   - Border bottom in lime green
   - Smooth scrolling to sections when clicked

2. HERO SECTION (Full viewport height)
   - Background: Dark gradient (black to dark gray)
   - Centered content with text alignment
   - "O'Brien Marketing Group" subheading in lime green, uppercase, ~0.9rem, letter-spaced
   - Main headline "We STRIVE so you THRIVE" in huge bold text (responsive 2.5rem-5rem depending on screen size)
   - Subtitle: "Screen Printing, Embroidery, Vinyl Wraps & Custom Promotional Solutions" in light gray
   - CTA Button "Get Started" with:
     - Lime green background
     - Black text
     - Uppercase, bold, letter-spaced
     - Padding: 1rem 2.5rem
     - On hover: slightly lighter green, lift effect (translateY), glow shadow
   - Location info below button: "605 Gilmer Rd | Longview, Texas" in smaller text

3. RESPONSIVE DESIGN
   - Mobile (0-767px): Single column, hamburger menu, large touch targets
   - Tablet/Desktop (768px+): Horizontal nav, standard layout
   - Hero text scales fluidly with viewport (clamp() function)
   - All text readable on small screens

4. FUNCTIONALITY
   - Hamburger menu toggles navigation on mobile
   - Navigation links scroll smoothly to sections (#services, #portfolio, #contact)
   - CTA button scrolls to contact section
   - All interactive elements have clear hover states
   - Keyboard focus visible on all links/buttons

5. CODE QUALITY
   - Single HTML file with embedded CSS and JavaScript
   - No external dependencies or frameworks
   - Mobile-first approach (mobile styles default, tablet+ added via media queries)
   - CSS organized in logical sections with comments
   - JavaScript handles menu toggle and smooth scrolling

OUTPUT: Single index.html file ready to test in browser. Next phases will add services, portfolio, and contact sections below this hero.
```

## PHASE 5: Polish, Testing & Deployment to Railway

```
Final phase. You have a complete index.html with all sections working.

PHASE 5 DELIVERABLES: Polish, Testing & Deployment

1. CODE CLEANUP & OPTIMIZATION
   - Review all CSS: consolidate duplicates, ensure consistent spacing
   - Review all JavaScript: clean up comments, ensure no console errors
   - Optimize images: ensure Unsplash URLs load fast
   - Minify CSS/JS if using build tools (or leave readable for now)
   - Check for accessibility: all interactive elements keyboard-accessible, focus visible

2. CROSS-BROWSER & DEVICE TESTING
   - Test on Chrome, Firefox, Safari (desktop)
   - Test responsive breakpoints: 320px, 768px, 1024px viewports
   - Test all hover effects work on desktop
   - Test all touch interactions on mobile (menu toggle, button clicks, form inputs)
   - Test form validation (name/email/message required fields)
   - Test smooth scrolling on all nav links

3. PERFORMANCE CHECKS
   - Lighthouse audit (check in browser DevTools)
   - Aim for 90+ on Performance, Accessibility, Best Practices
   - Fix any warnings
   - Check page load time (should be <2s)

4. DESIGN POLISH PASS
   - Review color contrast: all text readable (WCAG AA minimum)
   - Check spacing consistency (margins, padding, gaps)
   - Ensure all interactive elements have clear hover/focus states
   - Verify all text is properly sized and readable at different breakpoints
   - Check hero section scales properly on all screen sizes

5. FINAL CHECKS BEFORE DEPLOYMENT
   - Verify all links work (tel:, mailto:, social links)
   - Form displays success message correctly
   - Navigation menu closes after clicking link on mobile
   - No horizontal scrolling on any viewport size
   - All sections have proper spacing and background colors

6. DEPLOYMENT TO RAILWAY
   a) Create Railway Account (if not already):
      - Go to railway.app
      - Sign up with GitHub or email
   
   b) Create New Project:
      - Click "New Project"
      - Choose "Empty Project"
      - Name it: "omg-landing"
   
   c) Deploy Code:
      - In Replit: Click "Deploy" or use GitHub integration
      - OR: Create simple package.json + deploy from command line
      - OR: Use Railway CLI for direct deployment
   
   d) Configure Deployment:
      - Port: 3000 (default)
      - Environment: Node.js (if using simple server)
      - Domain: Railway will auto-generate URL (e.g., omg-landing.up.railway.app)
   
   e) Verify Live:
      - Visit deployed URL
      - Test all functionality one more time
      - Check page loads correctly on mobile via deployed URL

7. FINAL DELIVERABLES
   - Production URL on Railway (e.g., https://omg-landing.up.railway.app)
   - All code committed to Git (if using version control)
   - README with deployment instructions
   - List any custom features or future enhancements

8. OPTIONAL NEXT STEPS (Future Phases)
   - Replace Unsplash images with real OMG portfolio photos

   - Add testimonials section
   - Add pricing/packages section
   - Add FAQ section
   - Integrate with OMG's CRM for lead capture
```
